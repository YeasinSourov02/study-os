Important: using this on two computers

Each computer/browser stores its own data, including routines and study-time history. To move your latest data:

  1. On computer A, click Export backup.
  2. Transfer the downloaded JSON file using USB, Google Drive, or another method.
  3. On computer B, open this same HTML file, choose the JSON file under Import, then click Import.

Import replaces the destination computer's current data. Export a backup first if you need to preserve it. This app works offline after you save the HTML file; external resource links still need internet.
